# Data Analytics Portfolio

Welcome to my data analytics portfolio! This repository showcases my ability to analyze complex datasets, create meaningful visualizations, and derive actionable insights using **Power BI**, **Python**, and **SQL**.

## 📊 Projects Overview

### 1. **Global Graduate Skills & Employability Index Analysis**
Analyzing global graduate employment trends, skills gaps, and employability metrics across countries.
- **Dataset:** Global Graduate Skills and Employability Index (Kaggle)
- **Tools:** Power BI, Python
- **Key Metrics:** Employment rates, skills assessment, regional comparisons
- [View Project](./1-graduate-employability-analysis/)

### 2. **Healthcare Data Analysis Dashboard**
Analyzing patient health records, hospital readmission rates, and healthcare outcomes.
- **Dataset:** Hospital Readmission/Patient Health Records (Kaggle)
- **Tools:** Power BI
- **Key Metrics:** Mortality rates, readmission rates, length of stay
- [View Project](./2-healthcare-analysis/)

### 3. **Climate Change Trends Analysis**
Examining global temperature trends, CO2 emissions, and climate impacts over time.
- **Dataset:** NASA GISS Temperature / World Bank Climate Data (Kaggle)
- **Tools:** Power BI, Python
- **Key Metrics:** Temperature anomalies, CO2 levels, regional climate impacts
- [View Project](./3-climate-analysis/)

### 4. **Financial Market & Stock Analysis**
Tracking stock performance, volatility, and investment portfolio metrics.
- **Dataset:** S&P 500 Historical Data / Tech Stocks (Kaggle)
- **Tools:** Power BI
- **Key Metrics:** Stock trends, volatility, sector performance
- [View Project](./4-finance-analysis/)
